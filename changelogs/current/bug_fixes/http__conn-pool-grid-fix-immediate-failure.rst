Fixed a use-after-free in ``ConnectivityGrid::newStream`` when an initial connection pool attempt fails synchronously while an asynchronous Happy Eyeballs or HTTP/2 failover attempt remains in flight, and fixed ``ConnPoolImplBase`` passing a null host description on synchronous connection creation failure. This behavior can be temporarily reverted by setting runtime guard ``envoy.reloadable_features.conn_pool_grid_fix_immediate_failure`` to ``false``.
