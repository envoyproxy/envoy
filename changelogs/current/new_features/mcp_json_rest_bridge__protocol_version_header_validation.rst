Added validation of the ``MCP-Protocol-Version`` request header for stateless MCP ``2026-07-28`` requests. A missing, duplicated, or mismatched header (compared with ``params._meta["io.modelcontextprotocol/protocolVersion"]``) is rejected with a ``400`` ``HeaderMismatch`` (``-32020``) JSON-RPC error. A protocol version that is not supported for stateless requests is rejected with a ``400`` ``UnsupportedProtocolVersion`` (``-32022``) JSON-RPC error that lists the requested and supported versions.
