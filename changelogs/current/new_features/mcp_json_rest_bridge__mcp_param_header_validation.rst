Added validation of ``Mcp-Param-{name}`` request headers for MCP ``2026-07-28`` tools/call requests, configured per tool with the new :ref:`mcp_param_headers <envoy_v3_api_field_extensions.filters.http.mcp_json_rest_bridge.v3.ToolConfig.mcp_param_headers>` field. Each mapping names the header, the literal property path of the argument, and its ``STRING``, ``INTEGER`` or ``BOOLEAN`` type. A missing, unexpected, malformed, or mismatched header is rejected with a ``HeaderMismatch`` error.
