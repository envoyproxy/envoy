Dynamic Module Transport Socket (proto)
=======================================

.. _extension_envoy.transport_sockets.dynamic_modules:

This extension has the qualified name ``envoy.transport_sockets.dynamic_modules``


.. note::
  This extension is functional but has not had substantial production burn time,
  use only with this caveat.

  This extension is not hardened and should only be used in deployments
  where both the downstream and upstream are trusted.

.. tip::
  This extension extends and can be used with the following extension categories:


  - :ref:`envoy.transport_sockets.downstream <extension_category_envoy.transport_sockets.downstream>`

  - :ref:`envoy.transport_sockets.upstream <extension_category_envoy.transport_sockets.upstream>`



  This extension must be configured with one of the following type URLs:



  - :ref:`type.googleapis.com/envoy.extensions.transport_sockets.dynamic_modules.v3.DynamicModuleTransportSocket <envoy_v3_api_msg_extensions.transport_sockets.dynamic_modules.v3.DynamicModuleTransportSocket>`







.. _envoy_v3_api_msg_extensions.transport_sockets.dynamic_modules.v3.DynamicModuleTransportSocket:

extensions.transport_sockets.dynamic_modules.v3.DynamicModuleTransportSocket
----------------------------------------------------------------------------


:repo:`[extensions.transport_sockets.dynamic_modules.v3.DynamicModuleTransportSocket proto] <api/envoy/extensions/transport_sockets/dynamic_modules/v3/dynamic_modules.proto#L36>`

Configuration for a transport socket implemented by a dynamic module. The transport socket
performs the raw I/O for a connection and may transform the bytes that flow over it, for example
to implement a custom encryption scheme.

Example:

.. code-block:: yaml

  transport_socket:
    name: envoy.transport_sockets.dynamic_modules
    typed_config:
      "@type": type.googleapis.com/envoy.extensions.transport_sockets.dynamic_modules.v3.DynamicModuleTransportSocket
      dynamic_module_config:
        name: my_module
      transport_socket_name: my_transport_socket




.. code-block:: json
  :force:

  {
    "dynamic_module_config": {...},
    "transport_socket_name": ...,
    "transport_socket_config": {...},
    "implements_secure_transport": ...
  }

dynamic_module_config
  (:ref:`extensions.dynamic_modules.v3.DynamicModuleConfig <envoy_v3_api_msg_extensions.dynamic_modules.v3.DynamicModuleConfig>`, *REQUIRED*) Dynamic module configuration. See :ref:`dynamic module configuration
  <envoy_v3_api_msg_extensions.dynamic_modules.v3.DynamicModuleConfig>` for details.


.. _envoy_v3_api_field_extensions.transport_sockets.dynamic_modules.v3.DynamicModuleTransportSocket.transport_socket_name:


transport_socket_name
  (`string <https://developers.google.com/protocol-buffers/docs/proto#scalar>`_, *REQUIRED*) The name of the transport socket implementation in the dynamic module. This is passed to the
  module's ``envoy_dynamic_module_on_transport_socket_factory_config_new`` function.


.. _envoy_v3_api_field_extensions.transport_sockets.dynamic_modules.v3.DynamicModuleTransportSocket.transport_socket_config:


transport_socket_config
  (`Any <https://developers.google.com/protocol-buffers/docs/reference/google.protobuf#any>`_) Optional configuration for the transport socket. This is passed as bytes to the dynamic module.
  If not specified, no configuration bytes are passed to the module.


.. _envoy_v3_api_field_extensions.transport_sockets.dynamic_modules.v3.DynamicModuleTransportSocket.implements_secure_transport:


implements_secure_transport
  (`bool <https://developers.google.com/protocol-buffers/docs/proto#scalar>`_) Whether the transport socket implements secure transport. Set this to true for modules that
  provide encryption so that Envoy treats connections using this transport socket as secure. If
  not specified, defaults to false.
